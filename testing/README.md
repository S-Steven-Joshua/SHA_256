# SHA-256 RTL Verification

## Testing Overview

The SHA-256 RTL implementation was extensively verified using **randomized test cases** and a **Python-based reference model**.

The RTL input is constrained to a maximum of **31 characters**.

### Verification Flow

```text
        Random Input Generation
                 │
                 ▼
       Test Cases Written to File
                 │
                 ▼
          ┌──────────────┐
          │   Testbench  │
          │     RTL      │
          └──────┬───────┘
                 │
                 │ data_out
                 ▼
          ┌──────────────┐
          │   Compare    │
          └──────┬───────┘
                 ▲
                 │
          Python SHA-256
          Reference Model
                 │
                 ▼
          Expected Digest
```

## Test Methodology

1. **1,500,000 random test cases** were generated.
2. Each input was restricted to a maximum length of **31 characters**.
3. The generated inputs were stored in a test file.
4. A Python script read each test case and calculated its SHA-256 hash using Python's `hashlib`.
5. The expected SHA-256 digest from Python was compared against the **RTL `data_out`**.
6. Any mismatch between the Python reference and RTL output was recorded as a failure.

## Verification Summary

The RTL `hash_out` was compared against the SHA-256 digest generated by the Python reference model for **15 lakh (1.5 million) randomized inputs**.

**No failures were observed across all 1,500,000 test cases.**

This testing provides strong functional confidence in the SHA-256 RTL implementation for inputs up to **31 characters**.
